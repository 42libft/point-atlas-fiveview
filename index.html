Point Atlas Fiveview

文字やロゴを、見る方向へ割り当てる。

上・手前・右・奥・左の5方向へ、自分の文字や画像の輪郭を入れて点群を作ります。画像の処理と描画は、この端末で行います。

サンプルを試す / Try demo 自分の文字・ロゴで作る

インストール・アカウント登録は不要です。このデモを開いてもカメラは起動しません。

上 ○手前 A右 B奥 C左 ◇→ 全て自分の入力に変更できます

まず点群を動かす

  1. 「サンプルを試す」を開きます。黒い点を明るい背景に表示します。
  2. 「上・手前・右・奥・左」を押して、それぞれの形を見ます。ドラッグで回り込み、ホイールで距離を変えられます。
  3. 方向ごとの欄に短い文字を入れるか、「画像」から自分のPNG・JPEG・WebPを選びます。写真の色ではなく、しきい値で選んだ輪郭を使います。
  4. 「入力を反映」で更新し、「プロジェクト保存」でJSONを保存します。「開く」で五方向の入力と設定を復元できます。

サンプルは単純な文字・図形をコードから作っています。元の作品画像や誌面、人物写真は含みません。JSONを共有する際は、自分で入力したラベルも確認してください。

自分の画像を使ってARを準備する

  1. 制作画面の「AR出力」を押します。別の端末で使う場合は、保存したプロジェクトJSONをAR画面で読み込みます。
  2. 認識用の平らな画像を選ぶか、「自作ターゲットを使う」を押します。
  3. 「認識画像を保存」でPNGを保存し、印刷するか別の画面に表示します。歪ませず、模様全体が入るようにしてください。
  4. 「ターゲットを生成」で同じ画像を解析します。完了したら「ターゲットを保存」で .mind を保存できます。
  5. HTTPSのページで「ARを始める」を押し、必要なときだけカメラを許可します。生成に使った同じ認識画像へ向けます。「終了」で停止します。

「カメラなしで姿勢確認」では、カメラを起動せずに五方向の座標変換を確認できます。画像認識の実測とは異なります。

実機iPhone/Safari、実紙の認識、五方向へ回り込む追跡、長時間の熱・性能は未検証です。認識画像が斜めになる、画面外へ出るなどで追跡が切れる場合があります。

AR準備画面を開く
うまく見えないとき

短い文字や太い輪郭から試してください。細線・密な漢字・写真の輪郭・長文では欠けやすくなります。「図形を優先」と、背景に合う黒／白の点を試してください。

画像は8 MB・3200万画素以内で、256×256の輪郭に変換します。SVGやフルカラー再現には対応しません。固定形状では正反対の投影が鏡像になるため、任意の5画像が全て両立するとは限りません。

カメラが使えない場合はHTTPSを確認し、端末のブラウザー設定からカメラ許可を確認してください。LANのHTTPアドレスやファイルを直接開く方法ではARを利用できません。

Download / English quick start

Open Try demo, use the five view buttons, then enter your own short text or PNG/JPEG/WebP outlines. Save and reload projects as JSON. Processing stays on the device.

For AR, export the project, select a recognition image, save that image, compile its target, and point the camera at the same printed/displayed image. Camera access starts only after you press the AR start button. Physical iPhone/Safari and long-run tracking are unverified.

Download v0.1.1 (experimental) includes source and prebuilt static files. To serve the extracted web ZIP locally with an installed Python 3:

cd point-atlas-fiveview-web
python3 -m http.server 8000 --bind 127.0.0.1

Open http://127.0.0.1:8000/. This loopback address refers to the device running the server; use the HTTPS demo for a separate phone.
